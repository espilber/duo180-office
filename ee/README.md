# Enterprise de duo180 Office (`ee/`)

Este directorio está reservado para futuros módulos de empresa (por ejemplo,
despliegue privado y verificación de licencias sin conexión). Hoy está
intencionadamente vacío salvo este aviso y la licencia.

## Frontera de licencia

Todo lo que hay bajo `ee/` está cubierto por la
[licencia de empresa](LICENSE) incluida en esta carpeta, no por la licencia
Apache-2.0 que cubre el resto del repositorio. Mantener todo el código de
empresa detrás de este único directorio de primer nivel hace que la frontera de
licencia sea auditable y permite que el núcleo abierto siga siendo Apache-2.0
puro de forma permanente.

> Nota de este fork: `ee/` proviene del proyecto original GenOffice y su
> licencia pertenece a ese proyecto. En duo180 Office este directorio no tiene
> contenido ni desarrollo asociado; si no vas a usarlo, se puede eliminar.

## Contribuciones

`ee/` no acepta contribuciones externas. Los pull requests de fuera del equipo
mantenedor no deben modificar archivos de este directorio (se aplica mediante
CODEOWNERS). Consulta [CONTRIBUTING.md](../CONTRIBUTING.md).
